INSTALLATION GUIDE

1. Open Torn PDA and go to the Scripts section.

2. Create or import a userscript using the relevant script link above.

3. Enable the script, return to Torn and reload the page.

4. If a script asks for a Torn API key, use a key with only the permissions required. Never share your key publicly.

Updates may be available through PDA's remote update option. Always review the permissions and source code before installing third-party scripts.
